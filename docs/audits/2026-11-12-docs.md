# Audit 2026-11-12: docs
Commit: 8a67a06 · Areas: 6 · Findings: 5/21/36 · Dropped on checking: 0 (1 moved; 7 duplicates merged)

## Summary
The docs agree with the code on almost every concrete detail. That includes every SHA-256 and size pinned in LAYOUT.md (re-hashed), the vision and Full Stockfish pins, every `part-` class, and the cache and storage keys. It also covers the OAuth details, the CSP and service-worker lists, the CI jobs, the time controls and engine limits, and about 55 of the decisions log's 123 entries. Where the docs did drift, it is in three places. **Principles and privacy**: `docs/spec.md`'s principles say no verdicts show in a game and nothing leaves the browser unasked, but the critique shows in a game and the tablebase is on by default. README's data statement leaves out that the Stockfish switch sends a loaded game's moves to Lichess's cloud. **Renames that never reached the docs**: Play/Explore became Menu, Play vs Stockfish became Play vs computer, and Full Stockfish gained a threaded build. **Layout work since 2026-10-27**: one-column panels flow, the short window docks the transport bar, Game info is hidden in a game, the square-ish layout exists and the breakpoints moved. **The replay spec** still has Save analysis in Settings, one line per analysed position and Stop discarding the run, all three changed since. Two code bugs turned up. First, a Lichess link to a game that won't build closes the import dialog before failing, flips the board, and reports the error only in Settings › Game; variant games aren't refused at all. Second, the Leave this game dialog says a resumed game's clock waits for the next move, but it runs from the moment the game opens.
Hot spots (last 300 commits, docs): `docs/spec.md` 171, `CLAUDE.md` 56, `README.md` 42, `LAYOUT.md` 28, `docs/spec/replay.md` 20. Code: `app/game-video-core.jsx` 57, `app/game-app.jsx` 46, `app/free-board.jsx` 41, `app/shell.html` 35, `app/stockfish.jsx` 29.
